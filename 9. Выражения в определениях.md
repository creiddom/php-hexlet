Также они нужны, чтобы упрощать сложные вычисления.  
В этом уроке мы научимся делать это.

## Используем выражение

Допустим, нужно перевести евро в рубли через доллары.  
Например, один евро равен 1.25 доллара, а у нас есть 50 евро.

```php
<?php

$dollarsCount = 50 * 1.25;
print_r($dollarsCount);
```

Ранее мы записывали в переменную конкретное значение.  
А здесь справа от знака равно — **выражение**.  
Интерпретатор вычислит результат `62.5` и запишет его в переменную.

Для PHP неважно, что перед ним: `62.5` или `50 * 1.25` — оба варианта выражения вычисляются в одно и то же значение.

Любая строка — это выражение. Конкатенация строк тоже выражение.  
Интерпретатор вычисляет их и получает значение.

Примеры выражений:

```php
<?php

62.5             // 62.5
50 * 1.25        // 62.5
120 / 10 * 2     // 24
(int) '100'      // 100

"hello"          // "hello"
"Good" . "will"  // "Goodwill"
```

Теперь создадим переменные для курса валют и посчитаем сумму в рублях:  
1 доллар равен 60 рублям.

```php
<?php

$rublesPerDollar = 60;
$dollarsCount = 50 * 1.25; // 62.5
$rublesCount = $dollarsCount * $rublesPerDollar; // 3750

print_r($rublesCount);
```

Переменные могут участвовать в любых выражениях.  
При вычислении PHP подставляет их значения и выполняет нужные операции.

## Используем переменные с конкатенацией

Переменные можно использовать и при **склеивании строк**.  
Синтаксис при этом не меняется.

```php
<?php

$what = "Kings" . "road";
print_r($what); // => "Kingsroad"

// Конкатенируем строку и переменную
$first = "Kings";
$what = $first . "road";
print_r($what); // => "Kingsroad"

// Конкатенируем две переменные
$last = 'road';
$what = $first . $last;
print_r($what); // => "Kingsroad"
```

## Выводы

Переменные полезны не только для хранения информации.  
Они также упрощают сложные вычисления, если использовать их в выражениях.

В любом месте кода, где ожидается выражение, можно поставить вычисление — математическое или строковое.  
Программа всё равно останется корректной.  

По этой причине невозможно описать все случаи использования выражений —  
их комбинации почти бесконечны.
