## Что такое строка

Какие из этих пяти вариантов — строки?

```
'Hello'
'Goodbye'
'G'
' '
''
```

С первыми двумя все понятно: это точно строки. А что насчет остальных?  
Любой одиночный символ в кавычках — это строка, например `'G'`.  
Пустая строка `''` — это тоже строка.  
То есть строкой мы считаем все, что находится внутри кавычек, даже если это пробел, один символ или вообще отсутствие символов.

Ранее в уроках мы записывали строки в одинарных кавычках, но можно использовать и двойные:

```php
<?php

print_r("Dracarys!");
```

## Зачем нужны двойные кавычки

Представим, что нам нужно напечатать строчку `dragon's mother`.  
Апостроф перед буквой `s` — это такой же символ, как одинарная кавычка. Попробуем:

```php
<?php

print_r('Dragon's mother');
// PHP Parse error: syntax error, unexpected 's' (T_STRING), expecting ',' or ')'
```

Такая программа не будет работать. С точки зрения PHP строка началась с одинарной кавычки, а потом закончилась после буквы `n`.  
Дальше были символы `s mother` без кавычек — значит, это не строка.  
А потом была одна открывающая кавычка, которая так и не закрылась. Этот код синтаксически некорректен.

Здесь помогут двойные кавычки. Такой вариант программы отработает корректно:

```php
<?php

print_r("Dragon's mother");
```

Теперь интерпретатор знает, что строка началась с двойной кавычки, значит, завершиться должна на двойной кавычке.  
А одинарная кавычка внутри стала частью строки.

Верно и обратное: если внутри строки мы хотим использовать двойные кавычки, то саму строку нужно оформлять в одинарных.  
Количество кавычек внутри самой строки не имеет значения.

Теперь представим строку:

```
Dragon's mother said "No"
```

В ней есть и одинарные, и двойные кавычки. В этой ситуации нужно указать интерпретатору, что считать кавычку частью строки, а не концом.  
Для этого используется **экранирование** — добавление обратного слэша `\` перед специальным символом.

```php
<?php

// Экранируется только ", так как в этой ситуации
// двойные кавычки имеют специальное значение
print_r("Dragon's mother said "No"");
// => Dragon's mother said "No"
```

Нам нужно было добавить `\` перед двойными кавычками, но не перед апострофом, потому что сама строка создана с двойными кавычками.  
Если бы строка создавалась с одинарными кавычками, то символ экранирования нужен был бы перед апострофом, но не перед двойными кавычками.

```php
<?php

// \ выводится, если после него идет обычный символ
print_r("Death is \so terribly final");
// => Death is \so terribly final
```

Также можно вывести сам обратный слэш:

```php
<?php

print_r("\\"); // => ```

## Что такое экранирующие последовательности

Иногда нужно расположить несколько строк друг за другом.  
Для этого говорят интерпретатору «нажать Enter» — сделать перевод строки.  
Это можно сделать с помощью символа перевода строки `\n`:

```php
<?php

print_r("- Are you hungry?\n- Aaaarrrgh!");
```

Результат:

```
- Are you hungry?
- Aaaarrrgh!
```

`\n` — это специальный символ, который обозначает **Line Feed (LF)**.  
С точки зрения компьютера — это один невидимый символ перевода строки:

```php
<?php

strlen("a");    // 1
strlen("\n");   // 1 !!!
strlen("\n\n"); // 2 !!!
```

`\n` — это способ записать символ перевода строки, но сам перевод строки — это один невидимый символ.  
Так как количество знаков на клавиатуре ограничено, специальные символы реализуются в виде таких обозначений.

Экранирующие последовательности вроде `\n` работают только внутри двойных кавычек.  
Если нужно вывести `\n` именно как текст, можно добавить ещё один обратный слэш: `\\n`.

В Windows для перевода строк используется `\r\n`, но в разработке принято использовать только `\n`,  
так как она универсальна и одинаково работает в любых системах.

## Что такое конкатенация

Программы постоянно оперируют строками. Всё, что мы видим на сайтах, так или иначе представлено в виде текста.  
Этот текст чаще всего собирается из разных частей. Операция соединения строк называется **конкатенацией**.

Мы уже знаем математическую операцию сложения:

```php
<?php

print_r(5 + 3); // => 8
```

Можно также «сложить» две строки:

```php
<?php

print_r('Dragon' . 'stone'); // => Dragonstone
```

Склеивание строк происходит в том порядке, в котором записаны операнды.  
Левый операнд — левая часть строки, правый — правая.

```php
<?php

print_r('Kings' . 'wood');     // => Kingswood
print_r('Kings' . 'road');     // => Kingsroad
print_r("King's" . 'Landing'); // => King'sLanding
```

Пробел — это такой же символ, поэтому если поставить пробел в одной из частей строки,  
он появится и в итоговой строке:

```php
<?php

print_r("King's " . 'Landing'); // => King's Landing
print_r("King's" . ' Landing'); // => King's Landing
```

## Выводы

В этом уроке мы разобрали, что такое строки — это любой одиночный символ в кавычках.  
Кавычки могут быть одинарными и двойными.  
Если внутри строки встречаются оба типа кавычек, нужно использовать экранирование.

Если нужно сделать перевод строки, то для этого используется символ `\n` — пример **экранирующей последовательности**,  
которая работает только внутри двойных кавычек.

Также мы узнали, что можно не только складывать числа, но и строки.  
Операция соединения строк называется **конкатенацией**.
