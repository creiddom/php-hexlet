В этом уроке мы научимся **извлекать конкретные символы из строки**.  
Например, если сайт знает имя и фамилию пользователя и нужно вывести их в формате `A. Ivanov`, нужно получить первый символ имени.

---

## Основы извлечения символов

```php
<?php

$firstName = 'Alexander';

print_r($firstName[0]); // => A
```

Квадратные скобки с числом — это **оператор извлечения символа из строки**.  
Число внутри скобок называется **индексом** — позицией символа в строке.

- Индексы начинаются с **нуля** почти во всех языках программирования.  
  Поэтому первый символ имеет индекс `0`.  
- Индекс последнего символа равен `длина строки - 1`.

```php
<?php

$firstName = 'Alexander';

// Длина строки 9, поэтому последний индекс — 8
print_r($firstName[8]);  // => r
```

### Вопрос на самопроверку

```php
<?php

$magic = '\nyou';
print_r($magic[1]); // => ?
```

---

## Отрицательные индексы

PHP также позволяет использовать **отрицательные индексы**.  
В этом случае отсчёт идёт с конца строки:  
- `-1` — последний символ,  
- `-2` — предпоследний и т. д.

```php
<?php

$firstName = 'Alexander';

print_r($firstName[-1]); // => r
```

В отличие от обычной индексации, здесь отсчёт начинается с `-1`, а не с `0`.

---

## Использование переменных как индекса

Вместо конкретного числа можно использовать **переменную**.  
Это позволяет гибко выбирать символ в зависимости от логики программы.

```php
<?php

$firstName = 'Alexander';
$index = 0;

print_r($firstName[$index]); // => A
```

Индекс в квадратных скобках вычисляется перед обращением к строке.  
Такой способ удобен, если позиция символа определяется во время выполнения программы.
