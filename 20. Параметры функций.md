Функции могут не только возвращать значения, но и **принимать их в виде параметров**.  
Параметры позволяют передавать данные в функцию, делая её универсальной и гибкой.

---

## Что такое параметры функций

С параметрами мы уже сталкивались при работе со встроенными функциями PHP:

```php
<?php

// Принимает один параметр любого типа
print_r('я параметр');

// Принимает два числовых параметра:
// 1. Округляемое число
// 2. Количество знаков после запятой
round(10.1245, 3); // 10.125

// Принимает три строковых параметра:
// 1. Что ищем
// 2. На что заменяем
// 3. Где производим замену
str_replace('go', 'mo', 'google'); // 'moogle'
```

Каждая функция может требовать свои параметры — их количество и типы зависят от задачи.

---

## Пример функции с параметром

Создадим функцию `getLastChar()`, которая возвращает **последний символ строки**, переданной на вход.

```php
<?php

function getLastChar($str)
{
    return $str[-1];
}
```

Теперь её можно вызывать с разными аргументами:

```php
getLastChar('Hexlet'); // 't'

$name1 = 'Hexlet';
getLastChar($name1); // 't'

$name2 = 'Goo';
getLastChar($name2); // 'o'
```

🔹 Параметр `$str` — это **входная переменная** функции.  
Имя параметра не связано с именем переменной при вызове — главное, чтобы оно отражало смысл данных.

---

## Передача аргументов

Если вызвать функцию без обязательного параметра, PHP сообщит об ошибке:

```php
getLastChar(); // Ошибка
// ArgumentCountError: Too few arguments to function getLastChar(), 0 passed
```

Количество аргументов в вызове должно соответствовать количеству параметров в определении функции.

---

## Несколько параметров

Можно создавать функции, которые принимают **два, три и более параметров**.  
Они перечисляются в круглых скобках через запятую.

Пример — функция для нахождения среднего числа:

```php
<?php

function average($x, $y)
{
    return ($x + $y) / 2;
}

average(1, 5); // 3
average(1, 2); // 1.5
```

Здесь:
- `$x` и `$y` — входные параметры функции,
- `average()` возвращает результат вычисления среднего значения.

---

## Выводы

- Параметры — это значения, которые функция получает при вызове.  
- Имя параметра внутри функции не зависит от имени аргумента при вызове.  
- Количество и порядок параметров должны совпадать с аргументами.  
- Функции с параметрами позволяют обрабатывать разные данные, не дублируя код.
