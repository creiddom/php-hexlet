## Логический тип

В математике существуют операции сравнения, такие как `5 > 4` или `1 < 3`.  
В программировании они работают так же, но с небольшими изменениями в синтаксисе.  
Например, вместо `=` для равенства в PHP используется `==`,  
потому что `=` зарезервировано для присваивания.

Список операций сравнения:

| Оператор | Значение |
|-----------|-----------|
| `<`  | меньше |
| `<=` | меньше или равно |
| `>`  | больше |
| `>=` | больше или равно |
| `==` | равно |
| `!=` | не равно |

Примеры:

```php
<?php

$result = 5 > 4;
print_r($result); // => true
print_r('one' != 'one'); // => false
```

Результатом любой логической операции является одно из двух значений:  
**true** (истина) или **false** (ложь).  
Тип данных, который хранит такие значения, называется **bool**.

## Предикаты

Функции, которые возвращают `true` или `false`, называются **предикатами**.  
Например, функция, проверяющая, младенец ли ребёнок:

```php
<?php

function isInfant($age)
{
    return $age < 1;
}

// Для вывода логических значений используем var_dump()
var_dump(isInfant(3));   // => bool(false)
var_dump(isInfant(0.5)); // => bool(true)
```

По соглашению, имена предикатов начинаются с `is`, `has` или `can`:

- `isInfant()` — младенец ли?  
- `hasChildren()` — есть ли дети?  
- `isEmpty()` — пустой ли?  
- `hasErrors()` — есть ли ошибки?

## Комбинирование операций и функций

Логические выражения можно комбинировать с другими выражениями.  
Например, проверка чётности числа с использованием оператора `%` (остаток от деления):

```php
<?php

function isEven($number)
{
    return $number % 2 === 0;
}

isEven(10); // true
isEven(3);  // false
```

Сначала вычисляется арифметическое выражение `$number % 2`,  
а затем результат сравнивается с нулём при помощи `===`.

## Логические операторы

### И (&&)

Оператор `&&` обозначает **логическое И** (конъюнкция).  
Выражение истинно только если **оба** операнда истинны.

```php
($length >= 8 && $length <= 20)
```

Таблица истинности:

| A | B | A && B |
|---|---|---------|
| true | true | true |
| true | false | false |
| false | true | false |
| false | false | false |

---

### ИЛИ (||)

Оператор `||` обозначает **логическое ИЛИ** (дизъюнкция).  
Выражение истинно, если **хотя бы одно** из условий истинно.

| A | B | A \|\| B |
|---|---|-----------|
| true | true | true |
| true | false | true |
| false | true | true |
| false | false | false |

---

### Отрицание (!)

Оператор `!` обозначает **логическое отрицание**.  
Он меняет логическое значение на противоположное:

```php
<?php

function isEven($number)
{
    return $number % 2 === 0;
}

isEven(10);   // true
!isEven(10);  // false
!!isEven(10); // true
```

Отрицание часто используется, чтобы инвертировать результат без написания новой функции.

## Слабая типизация

PHP — язык со **слабой типизацией**.  
Он автоматически преобразует типы данных, если считает это логичным.

Примеры:

```php
<?php

print_r(true);   // => 1
print_r(false);  // => (пустая строка)
print_r(0 || 1); // => 1
```

Правила приведения типов:

- `0`, `null`, `''` → приводятся к `false`
- Всё остальное → приводится к `true`

Также стоит помнить про различие операторов `==` и `===`:

```php
var_dump('' === false); // => false
var_dump('' == false);  // => true
```

`==` выполняет неявное преобразование типов,  
а `===` проверяет строгое равенство — и значение, и тип.
