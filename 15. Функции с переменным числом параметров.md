В этом уроке разберём одну особенность некоторых функций.  
Они могут принимать **переменное число параметров**.  
Речь идёт не о значениях по умолчанию, а о функциях, которые могут получать **любое количество аргументов**.

---

## Что такое функции с переменным числом параметров

В PHP существуют функции, которые не ограничены жёстко по количеству принимаемых аргументов.  
Это значит, что их можно вызывать с двумя, тремя, пятью или даже сотней параметров — в зависимости от ситуации.

---

## Пример: функция max()

Функция `max()` находит **максимальное значение** среди переданных параметров.

```php
<?php

max(1, 10, 3);        // 10
max(1, -3, 2, 3, 2);  // 3
```

Интересно, сколько параметров она ожидает на вход?  
Если открыть документацию, увидим её сигнатуру:

```
max(mixed $value, mixed ...$values): mixed
```

Эта запись означает следующее:

- Функция принимает **один обязательный параметр** `$value`.  
- После него стоит `...$values` — это **оператор распаковки аргументов**.  
  Он указывает, что функция может принимать **любое количество дополнительных параметров**.  

В данном случае `max()` способна работать и с двумя, и с десятью значениями — PHP сам соберёт их в общий список и найдёт наибольший.

---

## Что означает многоточие (...) в сигнатуре

Многоточие (`...`) в определении функции указывает, что параметр — это **variadic parameter**  
(параметр с переменным количеством аргументов).  
На практике это значит:

- функция может принимать **неограниченное число аргументов**,  
- все переданные значения собираются в **массив** внутри функции.

---

### Пример пользовательской функции с `...`

```php
<?php

function sumAll(...$numbers)
{
    $sum = 0;
    foreach ($numbers as $n) {
        $sum += $n;
    }
    return $sum;
}

print_r(sumAll(1, 2, 3, 4)); // => 10
print_r(sumAll(5, 10));      // => 15
```

В этом примере `...$numbers` собирает все переданные аргументы в массив `$numbers`,  
и цикл `foreach` обрабатывает их.  

---

## Выводы

- Функции могут принимать **переменное количество параметров**.  
- В сигнатуре такие параметры обозначаются как `...$name`.  
- Пример встроенной функции — `max()`.  
- Можно создавать собственные функции с такой же гибкостью.
