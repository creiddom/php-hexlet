# Описание типов
**Основы PHP**

## Введение
Когда мы пишем на PHP, то редко задумываемся о типах данных. Например:

```php
<?php

function sayHelloTo($name)
{
    print_r("Hello, {$name}");
}
```
Эта функция ожидает строку, но PHP примет и массив:

```php
sayHelloTo([]);
// PHP Notice:  Array to string conversion
```

Это происходит из-за **динамической типизации**. Чтобы контролировать входные данные, используется механизм **type hinting**.

---

## Type Hinting (объявление типов)
Type Hinting позволяет явно указывать типы параметров:

```php
function sayHelloTo(int $name)
{
    print_r("Hello, {$name}");
}
```

PHP выполнит автоматическое приведение типов:

```php
sayHelloTo(false); // Hello, 0
sayHelloTo('1');   // Hello, 1
```

---

## Ошибки типов
Если тип данных не соответствует ожидаемому, PHP выдаст ошибку:

```php
function sayHelloTo(string $name)
{
    print_r("Hello, {$name}");
}

sayHelloTo([]);
// PHP Fatal error:  Uncaught TypeError
```

## Несколько параметров и необязательные типы

```php
function get(string $text, int $index, $default = null)
{
    $length = strlen($text);
    return ($index >= 0 && $index < $length) ? $text[$index] : $default;
}
```

Тип для `$default` не задан, так как он может быть любым.

---

## Nullable-типы
Типы данных не допускают `null`, если это не указано явно.

```php
function printStr(string $value)
{
    echo $value;
}
printStr(null);
// PHP Fatal error
```

Чтобы разрешить `null`, можно задать значение по умолчанию:

```php
function printStr(string $value = null)
{
    echo $value;
}
printStr(null);
```

---

## Возвращаемые типы
С версии PHP 7.2 можно указывать тип возвращаемого значения:

```php
function sum(int $a, int $b): int
{
    return $a + $b;
}
```

Если тип не совпадает, PHP сообщает об этом:
```
TypeError: Return value of sum() must be of the type integer, string returned
```

---

## Функции без возвращаемого значения

```php
function sayItLoud(string $text): void
{
    $loudText = "{$text}!";
    print_r($loudText);
}
```

`void` указывает, что функция ничего не возвращает.

---

## Строгие типы

Чтобы запретить автоматическое преобразование типов, используется директива:

```php
declare(strict_types = 1);
```

Пример:

```php
function AddIntAndFloat(int $a, float $b): int
{
    return $a + $b;
}

echo AddIntAndFloat(1.4, '2');
// Fatal error: типы не совпадают
```

---

## Обнуляемые типы (Nullable)

Знак `?` перед типом делает его **nullable** — допускающим `null`.

```php
function isPersonMrSmith(?string $person): bool
{
    // ...
}
```

Такая функция может принимать как строку, так и `null`.

```php
isPersonMrSmith(null); // OK
isPersonMrSmith();     // Fatal error
```

Для возвращаемых значений используется тот же принцип:

```php
public function getName(string $person): ?string
{
    // может вернуть строку или null
}
```
