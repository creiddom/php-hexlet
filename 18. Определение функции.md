Функции бывают **встроенные** и **определённые программистом**.  
С встроенными мы уже знакомы, а теперь научимся создавать собственные.

Создание собственных функций значительно упрощает написание и поддержку программ.  
Функции позволяют **объединять сложные операции** в одну логическую единицу.

---

## Что такое определение функции

Например, отправка письма на сайте — это довольно сложная операция, включающая подключение к серверу, формирование сообщения и отправку данных.  
Всё это можно «спрятать» за одним простым вызовом функции:

```php
<?php

// Гипотетический пример
// Место, откуда берётся функция
namespace Some\Email\Package\send;

$email = 'support@hexlet.io';
$title = 'Помогите';
$body = 'Я написал историю успеха, как я могу получить скидку?';

// Один маленький вызов — и много логики внутри
send($email, $title, $body);
```

Внутри себя подобная функция выполняет сложные действия, но снаружи выглядит просто и понятно.

## Пример определения функции

Создадим первую собственную функцию, которая выведет на экран приветствие:

```php
<?php

// Определение функции
// Определение не выполняет функцию — оно только создаёт её
function showGreeting()
{
  $text = 'Hello, Hexlet!';
  print_r($text);
}

// Вызов функции
showGreeting(); // => 'Hello, Hexlet!'
```

Функция определяется с помощью ключевого слова `function`, за которым следует **имя функции** и **пустые скобки** (если аргументов нет).  
Тело функции — это всё, что записано внутри фигурных скобок `{}`.  

Тело выполняется **только при вызове функции**.  
Каждый вызов — это отдельный запуск кода внутри функции.

---

## Пустое тело функции

Иногда функции создаются заранее, но пока ничего не делают.  
Минимальное определение функции, которая ничего не выполняет, выглядит так:

```php
<?php

function noop() {}

noop(); // Вызов есть, а смысла нет
```

Такие функции встречаются редко, но бывают полезны при проектировании систем — например, когда нужно временно «заглушить» вызов.

---

## Советы по именованию функций

- Имена функций должны быть **глаголами**, потому что функции **выполняют действия**.  
  Например: `calculateTax()`, `sendEmail()`, `openFile()`.  
- Названия должны быть **понятными** и отражать назначение функции.  
- В PHP принято использовать **camelCase** — начинать со строчной буквы, а каждое следующее слово писать с заглавной.

---

## Выводы

- Функции помогают **разделять код на логические блоки**.  
- Определение функции создаёт новую возможность, но не запускает её.  
- Тело функции выполняется только при вызове.  
- Пустые функции (`noop`) иногда используются как заготовки.  
- Хорошие имена функций делают код понятным и удобным для сопровождения.
