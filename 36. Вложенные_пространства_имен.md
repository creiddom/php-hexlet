# Вложенные пространства имен
**Основы PHP**

## Введение

В этом уроке рассматривается **вложенность пространств имен** в PHP и то, как она отражает структуру файлов в проекте.

Типовая структура проекта:

```
my-site/
  src/
    Formatters/
      Pretty.php
    Generator.php
  tests/
  composer.json
  README.md
```

Директория `src` предназначена для хранения исходного кода программы или сайта.

---

## Вложенность пространств имен

В отличие от языков вроде Python или Java, где структура пакетов жестко связана с файловой, в PHP эта связь реализована **на уровне соглашений**, а не правил.

Например, для файла `Pretty.php` можно задать пространство имен **вложенным образом**:

```php
<?php
namespace Formatters\Pretty;

function render($data)
{
    // some code
}
```

Такое объявление делает пространство `Pretty` **вложенным** внутри `Formatters`.

---

## Работа с вложенными пространствами

Вложенные пространства имен работают аналогично обычным.  
Например, если в другом файле вызывается функция из этого пространства:

```php
<?php
namespace Generator;

function generate($data)
{
    return \Formatters\Prettyender($data);
}
```

---

## Общие пространства проекта

Чтобы избежать конфликтов, каждое приложение или библиотека помещаются в **общее пространство имен**, отражающее название проекта.

Например, если проект называется `my-site`, то пространство имен для файлов внутри `src` будет выглядеть так:

```php
<?php
// src/Formatters/Pretty.php
namespace My\Site\Formatters\Pretty;

// some code
```

```php
<?php
// src/Generator.php
namespace My\Site\Generator;

// some code
```

Такой подход предотвращает пересечения с другими библиотеками и делает структуру более читаемой.

---

## Рекомендации

- Всегда начинайте пространства имен с **уникального префикса проекта**.
- Используйте **вложенность** для отражения файловой структуры.  
- Избегайте слишком общих имен (`App`, `Data`, `Core`, `Generator`), если они не обернуты в проектное пространство.
