# Конструкция Switch
**Основы PHP**

## Зачем нужен switch

Многие языки в дополнение к условной конструкции `if` включают в себя `switch`.  
Это специализированная версия `if`, созданная для случаев, когда выполняется **много проверок на равенство одного и того же значения**.

Например:

```php
if ($status === 'processing') {
    // Делаем раз
} elseif ($status === 'paid') {
    // Делаем два
} elseif ($status === 'new') {
    // Делаем три
} else {
    // Делаем четыре
}
```

Тот же код можно записать короче и выразительнее с помощью `switch`:

```php
switch ($status) {
    case 'processing': // status == processing
        // Делаем раз
        break;
    case 'paid': // status == paid
        // Делаем два
        break;
    case 'new': // status == new
        // Делаем три
        break;
    default: // else
        // Делаем четыре
}
```

---

## Устройство конструкции switch

`swtich` состоит из нескольких элементов:

1. **Ключевое слово `switch`**  
   Указывает, по какой переменной будет происходить выбор.
2. **`case` и `default`**  
   Варианты выбора (аналог `if` и `else`).
3. **`break`**  
   Предотвращает «проваливание» — переход к следующему `case` после выполнения нужного.
4. **Фигурные скобки `{ }`**  
   Обозначают начало и конец конструкции, но не создают отдельного блока кода.

---

## Пример использования

```php
switch ($count) {
    case 1:
        // Делаем что-то полезное
        break;
    case 2:
        // Делаем что-то полезное
        break;
    default:
        // Что-то делаем
}
```

## Возврат значений из switch

Если `switch` находится внутри функции, часто нужно вернуть результат наружу.  
Есть два подхода.

### 1. Через переменную

```php
function doSomethingGood($count)
{
    $result = '';

    switch ($count) {
        case 1:
            $result = 'one';
            break;
        case 2:
            $result = 'two';
            break;
        default:
            $result = null;
    }

    return $result;
}
```

### 2. Через `return` внутри case

```php
function doSomethingGood($count)
{
    switch ($count) {
        case 1:
            return 'one';
        case 2:
            return 'two';
        default:
            return null;
    }
}
```

---

## Когда использовать switch

`swtich` не обязателен — любую задачу можно решить с `if`.  
Но он делает код **более читаемым**, когда нужно проверить **конкретные значения одной переменной**.
