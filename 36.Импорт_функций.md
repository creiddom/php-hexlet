# Импорт функций
**Основы PHP**

## Проблема длинных пространств имен

Использование пространств имен делает код более организованным, но при этом приводит к длинным вызовам функций:

```php
<?php

require_once(__DIR__ . '/src/Formatters/Pretty.php');

namespace Generator;

function generate($data)
{
    return \Formatters\Prettyender($data);
}
```
Если таких вызовов становится много, код теряет читаемость. Для решения этой проблемы в PHP существует **механизм импорта функций**.

---

## Импорт функций с помощью `use function`

Оператор `use function` позволяет «импортировать» функцию в текущее пространство имен, делая её доступной напрямую:

```php
<?php

require_once(__DIR__ . '/src/Formatters/Pretty.php');

namespace Generator;

use function Formatters\Prettyender;

function generate($data)
{
    return render($data);
}
```
Теперь вызов `render()` работает, как если бы функция была определена прямо внутри текущего пространства `Generator`.

---

## Несколько импортов

Количество импортируемых функций не ограничено. Можно подключать любое количество функций из разных пространств:

```php
<?php

require_once(__DIR__ . '/src/Pairs.php');

namespace Php\Pairs\Data\Lists;

use function Php\Pairs\Pairs\cons;
use function Php\Pairs\Pairs\car;
use function Php\Pairs\Pairs\cdr;
use function Php\Pairs\Pairs	oString;
```
Теперь все эти функции можно использовать без указания полного пути.

## Алиасы (псевдонимы)

Иногда возникает конфликт имён:  
- функция с таким именем уже определена, или  
- та же функция была импортирована ранее из другого пространства.

Чтобы избежать конфликта, можно задать **псевдоним (алиас)** с помощью ключевого слова `as`:

```php
<?php

require_once(__DIR__ . '/src/Formatters/Pretty.php');
require_once(__DIR__ . '/src/Formatters/Simple.php');

namespace Generator;

use function Formatters\Prettyender;
use function Formatters\Simpleender as simpleRender;

function generate($data)
{
    return simpleRender($data);
}
```
В этом примере функция `Formatters\Simple\render()` импортируется под именем `simpleRender` и теперь доступна под этим именем в текущем пространстве.

---

## Итог

- `use function` упрощает обращение к функциям из других пространств.  
- Можно импортировать любое количество функций.  
- Конфликты решаются через **алиасы (as)**.
