# Дата и время
**Основы PHP**

## Время

Часы компьютера делятся на **аппаратные** (имеют батарею) и **системные** (управляются ОС).  
Время в Unix-системах хранится в формате **Unix Time** — количество секунд, прошедших с момента:

> 00:00:00 UTC 1 января 1970 года (четверг)

Этот момент называют **Unix Epoch**, а конкретное значение времени — **timestamp**.  
Получить текущее значение можно с помощью функции `time()`:

```php
<?php
time(); // 1532435204
```

---

## Дата

Функция `date()` преобразует timestamp в читаемую дату.  
Первый параметр определяет формат вывода:

```php
<?php
date('Y'); // 2018
```

Если timestamp не передан, используется текущее время.  
Передача собственного значения:

```php
<?php
date('M', 123123123); // Nov
```

Формат можно комбинировать:

```php
<?php
date('l jS \of F Y h:i:s A'); // Thursday 26th of July 2018 10:58:55 AM
```

---

## Функция mktime()

Функция `mktime()` создаёт timestamp из указанных параметров времени и даты.

```php
<?php
mktime(0, 0, 0, 7, 1, 2000); // 962409600
```

Сигнатура функции:

```php
mktime(
    int $hour,
    ?int $minute = null,
    ?int $second = null,
    ?int $month = null,
    ?int $day = null,
    ?int $year = null
): int|false
```

## Часовые пояса

Земля разделена на **24 часовых пояса**, и время в соседних отличается примерно на час.  
Нулевым временем считается **UTC** (всемирное координированное время).  
Например, Москва — `UTC+3`.

Переход на летнее и зимнее время регулируется странами, а смещения происходят относительно UTC.

**Главное правило**:  
> хранить и сравнивать даты нужно в UTC, а выводить — в локальной таймзоне пользователя.

Проверка и изменение часового пояса:

```php
<?php
date_default_timezone_get(); // возвращает текущую таймзону
date_default_timezone_set('Europe/Moscow'); // устанавливает новую
```
