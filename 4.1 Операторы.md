# Операторы

## Определение

**Оператором** называется то, что принимает одно или больше значений (или выражений, если говорить на жаргоне программирования), и вычисляет новое значение; поэтому всю конструкцию рассматривают как выражение.

Операторы группируются по количеству принимаемых значений.  
**Унарные операторы** принимают только одно значение — например, `!` (оператор логического отрицания) или `++` (инкремент).  
**Бинарные операторы** принимают два значения — это, например, знакомые каждому арифметические операторы `+` (плюс) и `-` (минус). Большая часть поддерживаемых в PHP операторов входит именно в эту категорию.  
И наконец, в языке предусмотрен только **один тернарный оператор** `?:`, который принимает три значения. Его часто называют просто «тернарным оператором» или «условным оператором».

Полный список PHP-операторов перечислен в разделе **«Приоритет оператора»**.  
Раздел также описывает порядок выполнения и ассоциативность операторов. Порядок и ассоциативность определяют, как вычисляются выражения с несколькими разными операторами.

---

## Приоритет операторов

Приоритет оператора определяет, насколько «тесно» он связывает между собой два выражения.  
Например, выражение `1 + 5 * 3` вычисляется как `16`, а не `18`, поскольку у оператора умножения `*` более высокий приоритет, чем у оператора сложения `+`.

Порядок выполнения операторов можно изменить круглыми скобками, например:  
`(1 + 5) * 3` вычисляется как `18`.

Выполнятся ли операторы с равным приоритетом слева направо или справа налево, определяет **ассоциативность**.  
Например, оператор `-` относится к левоассоциативным, поэтому выражение `1 - 2 - 3` сгруппируется как `(1 - 2) - 3` и вычислится в `-4`.  
При этом оператор `=` относится к правоассоциативным, поэтому выражение `$a = $b = $c` сгруппируется как `$a = ($b = $c)`.

Неассоциативные операторы с одинаковым приоритетом нельзя указывать совместно.  
Например, выражение `1 < 2 > 1` не сработает в PHP.  
При этом выражение `1 <= 1 == 1` сработает, поскольку у оператора `==` более низкий приоритет, чем у `<=`.

Ассоциативность касается только двоичных и тернарных операторов.  
Унарные операторы бывают префиксными или постфиксными, поэтому понятие ассоциативности к ним не относится.  
Например, `!!$a` сгруппируется только как `!(!$a)`.

Скобки, даже если они необязательны, часто улучшают читаемость кода за счёт явной группировки, а не опоры на приоритеты и ассоциативность.

Следующая таблица приводит список операторов, отсортированный по убыванию приоритетов.  
У операторов, которые перечислены в одной строке, одинаковый приоритет, а порядок выполнения этих операторов определяется группировкой.

## Примеры

```php
<?php
$a = 3 * 3 % 5; // (3 * 3) % 5 = 4
var_dump($a);

$a = 1;
$b = 2;
$a = $b += 3; // $a = ($b += 3) -> $a = 5, $b = 5
var_dump($a, $b);
?>
```

```php
<?php
$a = true ? 0 : (true ? 1 : 2);
var_dump($a);
?>
```

```php
<?php
$a = 1;
echo $a + $a++; // может вывести 2 или 3 в зависимости от версии PHP
$i = 1;
$array[$i] = $i++; // индекс может быть 1 или 2
?>
```

```php
<?php
$x = 4;
echo "x минус 1 равно " . $x - 1 . ", ну, я надеюсь\n";
echo "x minus one equals " . ($x - 1) . ", ну, я надеюсь\n";
?>
```

## Изменения в версиях PHP

- **8.0.0:** оператор `.` теперь имеет более низкий приоритет, чем `+`, `-`, `<<`, `>>`.  
- **8.0.0:** тернарный оператор `?:` стал неассоциативным.  
- **7.4.0:** не рекомендуется полагаться на приоритет `.` при арифметических операциях и побитовом сдвиге.

## Примечание пользователей

Будьте внимательны к разнице между `and` и `&&`, а также `or` и `||`.  
`and` и `or` имеют более низкий приоритет, чем `=`, а `&&` и `||` — более высокий.

```php
<?php
$bool = true && false;
var_dump($bool); // false

$bool = true and false;
var_dump($bool); // true — из-за приоритета операторов
?>
```

```php
<?php
$a = [];
$a['aa'] ?? 'not set'; // not set (ожидаемо)
"lets see if it is set" . $a['aa'] ?? 'not set'; // выдаст notice и "lets see if it is set"
"lets see if it is set" . ($a['aa'] ?? 'not set'); // правильный вариант
?>
```
