## Именование переменных

Рассмотрим пример кода:

```php
<?php

$x = 'Father!';
print_r($x);
print_r($x);
```

Программа работает, но имя переменной `$x` ничего не говорит о её назначении.  
Компьютеру всё равно, как мы называем переменные, но для людей **понятные имена — ключ к читаемости кода**.

Мы читаем код гораздо чаще, чем пишем. И часто приходится читать не свой код, а чужой.  
Поэтому лучше потратить время и выбрать осмысленное имя, чем потом искать, что означает `$x`.

Хорошие имена позволяют понять смысл переменной **без контекста**.  
Например, `$greeting` ясно указывает, что это приветствие.

## Стандарты именования

Существует несколько стилей для составных имён переменных:

| Стиль | Пример | Особенности |
|--------|---------|-------------|
| kebab-case | `my-super-var` | Используется дефис. В PHP не применяется. |
| snake_case | `my_super_var` | Часто встречается в других языках. |
| CamelCase | `MySuperVar` | Первое слово с заглавной буквы. |
| lowerCamelCase | `mySuperVar` | Первое слово со строчной буквы. Используется в PHP. |

В PHP принят стиль **lowerCamelCase** — первая буква строчная, следующие слова начинаются с заглавной:  
```php
$userName;
$mySuperVariable;
```

Также важно придерживаться **английского языка** при именовании.  
Использование транслита вроде `$privet` или `$summaZakaza` недопустимо.  
Если трудно подобрать слово, воспользуйтесь переводчиком — со временем привычка придёт.

Код в современных проектах — это **командная работа**, и единый стиль именования облегчает взаимодействие.  
В PHP действует набор стандартов PSR (PHP Standards Recommendations), которые описывают правила оформления кода.  
Они поддерживаются автоматически с помощью линтеров — программ, проверяющих стиль кода.

## Именование функций

Функции именуются в том же стиле — **lowerCamelCase**, но при выборе слов важно другое.  
Функция обычно **выполняет действие**, поэтому её имя — это **глагол**:

Примеры:
- `showDate()` — показать дату  
- `sub()` — вычесть  
- `print_r()` — напечатать  
- `round()` — округлить  
- `gettype()` — получить тип

Переменные, напротив, обозначают **сущности** — это существительные:
- `$child` — ребёнок  
- `$result` — результат  
- `$euros` — евро

📘 Правило: **функция — глагол, переменная — существительное.**

## Магические числа

Посмотрим пример:

```php
<?php

$eurosCount = 1000;
$dollarsCount = $eurosCount * 1.25; // 1250
$rublesCount = $dollarsCount * 60;  // 75000

print_r($rublesCount);
```

Программа работает, но числа `1.25` и `60` непонятны.  
Откуда они взялись? Что означают?  

Такие числа называют **магическими** (*magic numbers*) — значения, смысл которых неочевиден из кода.  
Понять их можно только с глубоким знанием контекста, что ухудшает читаемость.

Решение — вынести числа в переменные с осмысленными именами:

```php
<?php

$dollarsPerEuro = 1.25;
$rublesPerDollar = 60;

$eurosCount = 1000;
$dollarsCount = $eurosCount * $dollarsPerEuro;   // 1250
$rublesCount = $dollarsCount * $rublesPerDollar; // 75000

print_r($rublesCount);
```

Теперь код понятен с первого взгляда.  
Мы сразу видим, что происходит конвертация валют, а не просто умножение чисел.

Дополнительно улучшает читаемость **пустая строка** между объявлениями переменных и вычислениями.  
Код стал длиннее, но гораздо понятнее — а читаемость всегда важнее краткости.

## Выводы

- Хорошие имена переменных и функций делают код понятным.  
- В PHP используется стиль **lowerCamelCase**.  
- Переменные — существительные, функции — глаголы.  
- Не используйте транслит — только английский.  
- Избегайте **магических чисел**, давая значениям смысл через имена.  
- Понятный код всегда важнее короткого.
