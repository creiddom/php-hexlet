# Цикл for
**Основы PHP**

## Общие сведения

Цикл **for** используется в ситуациях, когда количество итераций известно заранее.  
Он более удобен и лаконичен, чем `while`, если нужно повторить действие фиксированное число раз.

Пример переворота строки с помощью `for`:

```php
<?php

function reverseString($str)
{
    $result = '';

    for ($i = 0; $i < strlen($str); $i += 1) {
        $currentChar = $str[$i];
        $result = "{$currentChar}{$result}";
    }

    return $result;
}
```

Цикл читается так:
> Повторять, пока условие `$i < strlen($str)` истинно, увеличивая `$i` на 1 после каждой итерации.

---

## Структура цикла for

В круглых скобках цикла указано три выражения:
1. **Инициализация** — выполняется один раз перед первой итерацией (`$i = 0`).
2. **Условие (предикат)** — проверяется перед каждой итерацией (`$i < strlen($str)`).
3. **Изменение счетчика** — выполняется в конце каждой итерации (`$i += 1`).

Цикл `for` эквивалентен конструкции `while`, но выглядит компактнее и удобнее для чтения.

## Синтаксический сахар

В PHP часто используются сокращённые формы записи арифметических операций.  
Это делает код короче, но результат остаётся тем же:

| Полная запись | Сокращённая форма |
|----------------|-------------------|
| `$a = $a + 1` | `$a += 1` |
| `$a = $a - 1` | `$a -= 1` |
| `$a = $a * 2` | `$a *= 2` |
| `$a = $a / 1` | `$a /= 1` |
| `$a = $a . 'bla'` | `$a .= 'bla'` |

Такой синтаксис называют **синтаксическим сахаром** — он "подслащивает" код, упрощая запись.

## Инкремент и декремент

В PHP, как и в языке C, есть две специальные операции:
- **Инкремент** (`++`) — увеличивает значение переменной на 1.
- **Декремент** (`--`) — уменьшает значение переменной на 1.

Пример:

```php
$i = 0;
$i++; // 1
$i--; // 0
```

### Префиксная и постфиксная формы

Разница между `++$i` и `$i++` заключается в порядке выполнения:

```php
$x = 5;

echo ++$x; // => 6 (увеличение, потом вывод)
echo $x;   // => 6

echo $x++; // => 6 (вывод, потом увеличение)
echo $x;   // => 7
```

**Префиксная форма** сначала изменяет переменную, потом возвращает значение.  
**Постфиксная форма** сначала возвращает текущее значение, потом изменяет переменную.

---

## Рекомендации

- Не используйте `++` и `--` внутри сложных выражений:  
  ```php
  $x = $i++ - 7 + --$h; // плохо читается
  ```
- Применяйте их отдельно, на отдельных строках.
- Избегайте смешения операций с побочными эффектами и без них.
