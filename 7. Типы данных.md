## Какие бывают типы данных

Существуют разные способы представлять данные в программах:

- **Строки** — наборы символов в кавычках, вроде `"Hello, World!"`
- **Целые числа** — например, `7`, `-198`, `0`

Это две разные категории информации — два разных **типа данных**.

Операция умножения имеет смысл для чисел, но не имеет смысла для строк.  
Тип данных определяет, какие операции допустимы для значений.

Язык программирования распознает типы. PHP не позволит умножать текст на текст,  
но позволит умножать числа. Типы защищают программы от ошибок.

В отличие от строк, числа **не нужно оборачивать в кавычки**.  
Чтобы напечатать число 5, достаточно написать:

```php
<?php

print_r(5);
```

Число `5` и строка `'5'` — разные вещи, хотя вывод у `print_r()` одинаковый.

**Целые числа** (`1`, `34`, `-19`) и **рациональные числа** (`1.3`, `1.0`, `-14.324`) — это два отдельных типа данных.  
Такое разделение связано с особенностями устройства компьютеров.

Пример с рациональным числом:

```php
<?php

print_r(10.234);
```

Типы данных `строка`, `целое число` и `рациональное число` — это **примитивные типы**, встроенные в язык PHP.  
Кроме них существуют **составные типы данных**, но пока мы будем работать только с примитивными.

Программисты также могут создавать собственные типы данных.

> 💡 В английском языке:  
> - строка данных — *string*  
> - строка текста в файле — *line*

## Что такое слабая типизация

Рассмотрим пример:

```php
<?php

print_r(1 + '7'); // => 8
```

`'7'` — это строка, а не число.  
Однако PHP выдал ответ `8`, как если бы мы складывали два числа.  
Когда интерпретатор видит несоответствие типов, он пытается преобразовать их автоматически.  
В данном случае он преобразовал строку `'7'` в число `7` и сложил `1 + 7`.

PHP — **язык со слабой типизацией**. Он знает о типах, но не заставляет строго их соблюдать.  
Если это кажется логичным, он делает **автоматическое преобразование типов**.

В языках со строгой типизацией такое выражение вызвало бы ошибку.

PHP был создан для интернета, где вся информация передаётся как строки.  
Поэтому создатели языка решили, что автоматическое преобразование удобно.

Однако слабая типизация часто приводит к ошибкам, которые сложно отследить.  
Код может иногда работать, а иногда — нет, в зависимости от того, как PHP «догадался» преобразовать тип.

## Как явно преобразовать типы

Чтобы избежать неожиданностей, можно **явно указывать** тип с помощью специального синтаксиса.

Пример явного преобразования типов:

```php
<?php

// Примеры немного искусственные
// В реальности этот механизм полезен при работе с переменными
print_r((string) 5);
print_r((int) '345');

// Преобразование типов можно использовать внутри выражений
print_r('Это ' . ((string) 5)); // => 'Это 5'
```

Явное преобразование работает так:  
перед значением в скобках указывается желаемый тип.  
Значение справа преобразуется в тип, указанный слева.

Более сложный пример:

```php
<?php

(string) (5 + ((int) '4'));
```

Порядок вычисления:

```php
(int) '4';  // 4
5 + 4;      // 9
(string) 9; // '9'
```

## Выводы

В этом уроке мы разобрали работу с типами данных — со строками и числами.  
Мы узнали, что PHP — язык **со слабой типизацией**, который автоматически преобразует типы при необходимости.

Например, `'7'` — строка, но PHP может воспринять её как число и сложить с другим числом.  
Однако полагаться на слабую типизацию опасно — она может вызвать неожиданные ошибки.

Поэтому во многих ситуациях лучше делать **явное преобразование типов**.  
Такой код предсказуем и безопасен.
