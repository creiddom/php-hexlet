## Функция abs()

Функция `abs()` возвращает **абсолютное значение числа** и принимает один параметр — число.

Если вызвать `abs()` **без параметров**, PHP сообщит об ошибке:

```
TypeError: abs() expects exactly 1 argument, 0 given
```

Так интерпретатор указывает, что функция ожидает один аргумент, а мы не передали ни одного.

Параметром `abs()` может быть только число.  
Если попытаться передать строку, PHP также вернёт ошибку:

```
TypeError: abs(): Argument #1 ($num) must be of type int|float, string given
```

Результат вызова этой функции — всегда **число**.

---

### Что такое сигнатура функции

Сигнатура функции определяет:
- количество входных параметров;
- их типы;
- тип возвращаемого значения.

Пример из официальной документации PHP:

```
abs(int|float $num): int|float
```

🧩 Расшифровка:
- функция называется `abs`;
- принимает один параметр `$num`, который может быть целым или дробным числом (`int|float`);
- возвращает число (`int|float`);
- возвращает абсолютное значение параметра `$num`.

Функции могут принимать несколько параметров, но порядок аргументов всегда должен соответствовать порядку в сигнатуре.  
Любая функция возвращает **только одно значение** — это ограничение языка PHP.

## Аргументы по умолчанию

Рассмотрим функцию `round()`.  
Она округляет переданное число.

```php
<?php

$result = round(10.25, 0); // 10
```

Мы передали два аргумента:
1. число для округления,
2. точность (0 означает округление до целого).

Чаще всего округляют именно до целого числа, поэтому второй аргумент в `round()` **необязательный** — у него внутри задано значение по умолчанию `0`.

То есть можно вызвать функцию и без второго параметра:

```php
<?php

$result = round(10.25); // 10
```

Если нужна другая точность, можно передать её явно:

```php
<?php

$result = round(10.25, 1); // 10.3
```

---

### Особенности аргументов по умолчанию

- Необязательные аргументы всегда идут **после обязательных**.  
- Их количество может быть любым, но они должны находиться **в конце списка аргументов**.  
- Если аргумент не указан при вызове, используется значение по умолчанию, определённое в сигнатуре.

---

## Выводы

- Сигнатура функции показывает, **какие параметры и типы данных** она принимает и что возвращает.  
- Функция `abs()` принимает одно число и возвращает его абсолютное значение.  
- Функция `round()` имеет **аргумент по умолчанию**, что позволяет вызывать её с одним или двумя параметрами.  
- Все функции в PHP возвращают **только одно значение**.
