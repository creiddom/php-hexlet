# Отладка
**Основы PHP**

## Типы ошибок

**Отладка** — один из важнейших навыков программиста. Она помогает анализировать и исправлять ошибки, возникающие в коде.

Сообщения об ошибках в PHP всегда отображаются **на английском языке**, и важно **читать и понимать их**, а не «подбирать решения наугад».

Пример вывода ошибки:

```
Error: Call to undefined function App\Users\undef()

/usr/src/app/src/Users.php:9
/usr/src/app/tests/UsersTest.php:27
```

### 🔹 Бэктрейс (stack trace)

Бэктрейс — это список всех вызовов функций **в обратном порядке**, от последнего вызова (ошибки) к первому.  
Он помогает понять, **где и после чего** произошёл сбой.

### 🔹 Основные шаги при отладке:

1. Перевести и понять сообщение об ошибке.  
2. Найти в бэктрейсе строку в **вашем коде**, где ошибка возникла.

## Основные типы ошибок

| Тип ошибки | Пример | Описание |
|-------------|--------|----------|
| **Синтаксическая** | `PHP Parse error: syntax error, unexpected '}'` | Ошибка записи кода (например, пропущена `;`) |
| **Программная** | Вызов несуществующей функции или передача аргумента неверного типа | Ошибка логики в коде |
| **Логическая** | Программа работает, но даёт неверный результат | Самая сложная категория |

Пример логической ошибки:

```php
<?php
function sum($a, $b)
{
    return $a - $b; // Ошибка: нужно сложение
}
```

## Отладка кода

Отладка — это процесс **анализа изменения переменных** во время работы программы.

Пример функции с ошибкой:

```php
<?php
function sumOfSeries($start, $finish)
{
    $sum = 0;
    for ($i = $start; $i < $finish; $i++) {
        $sum += $i;
    }

    return $sum;
}
```

Ошибка неочевидна. Чтобы найти её, нужно **посмотреть, какие значения получают переменные** `$i` и `$sum` на каждой итерации:

```php
<?php
function sumOfSeries($start, $finish)
{
    $sum = 0;
    for ($i = $start; $i < $finish; $i++) {
        print_r('new iteration !!!!');
        print_r($i);
        $sum += $i;
        print_r($sum);
    }

    return $sum;
}

sumOfSeries(3, 5);

// Вывод:
// new iteration !!!!
// 3
// 3
// new iteration !!!!
// 4
// 7
```

Из вывода видно, что не учитывается последнее число `$finish`.  
Причина — в условии `($i < $finish)` вместо `($i <= $finish)`.

## Отладочная печать

Для быстрой проверки используют:

- `print_r()` — выводит значение переменной (но без переноса строки);
- `dump()` — красиво выводит значение;
- `dd()` — выводит значение и **останавливает выполнение** программы.

```php
<?php
$var = 'hello, world!';
dump($var);
```

`dump()` особенно полезна при работе с **массивами и структурами данных**, которые скоро будут изучаться далее.
