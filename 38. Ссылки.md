# Ссылки
**Основы PHP**

## Введение
Ссылки в PHP — это механизм, позволяющий обращаться к **одному и тому же значению через разные переменные**.  
Хотя ссылки используются нечасто напрямую, важно понимать их принцип, особенно перед изучением массивов и объектов.

---

## Доступ без ссылок

```php
$a = 5;
$b = $a;
$a = 3;
echo $b; // => 5
```
Переменные `$a` и `$b` здесь независимы: изменение одной не влияет на другую.

---

## Доступ через ссылку

```php
$a = 5;
$b =& $a;
$a = 3;
echo $b; // => 3
```
Оператор `=&` указывает, что обе переменные **ссылаются на одно и то же значение**.  
Изменения в `$a` отразятся в `$b`, и наоборот.

---

## Как это работает
Переменные и значения в PHP существуют отдельно.  
Когда выполняется `$b = $a`, значение `$a` **копируется** в `$b`.  
Когда выполняется `$b =& $a`, обе переменные начинают ссылаться на **одно и то же значение**.

---

## Основные операции со ссылками

1. **Присвоение по ссылке**
   ```php
   $b =& $a;
   ```

2. **Передача по ссылке**
   ```php
   function changeValue(&$var)
   {
       $var = 10;
   }

   $x = 5;
   changeValue($x);
   echo $x; // 10
   ```

3. **Возврат по ссылке**  
   Используется редко и в основном в системных функциях.

---

## Передача по ссылке в функции

```php
function strangeFunction(string &$text)
{
    $text = 'hei';
}

$text = 'money';
strangeFunction($text);
echo $text; // => hei
```
Аргумент функции передается по ссылке, поэтому внутри функции можно изменить исходную переменную.  
Такие функции обычно **ничего не возвращают**, так как результат уже отражается в переданных аргументах.  
Это считается **плохой практикой**, если не требуется высокая производительность.
