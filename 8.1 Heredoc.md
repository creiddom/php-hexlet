# Heredoc в PHP

## Введение

Heredoc — это один из способов задания строк в PHP, аналогичный использованию двойных кавычек.  
Он используется для создания многострочных строк, в которых можно использовать переменные и управляющие последовательности.

Синтаксис heredoc начинается с оператора `<<<`, за которым следует идентификатор, затем перевод строки и сам текст.  
Завершается блок тем же идентификатором, который должен находиться в начале строки.

```php
<?php
echo <<<END
a
b
c
END;
```
Результат:
```
abc
```

---

## Синтаксис

- После `<<<` следует идентификатор (название, придуманное программистом).  
  Оно может содержать только буквы, цифры и подчёркивания, но не может начинаться с цифры или подчёркивания.
- После идентификатора обязательно идёт перевод строки.
- Строка с закрывающим идентификатором должна быть первой в строке (начинаться в позиции 0) и совпадать с открывающим идентификатором.
- После закрывающего идентификатора допускается `;` или продолжение выражения.
- Пробелы, табуляции или другие символы после закрывающего идентификатора не допускаются.
- Если встретится строка, совпадающая с закрывающим идентификатором, она будет воспринята как конец heredoc.

Пример:
```php
<?php
$str = <<<EOD
Пример строки,
записанной heredoc-синтаксисом
в несколько строк.
EOD;
echo $str;
```

---

## Нововведения в PHP 7.3 и выше

В PHP 7.3 добавлена возможность использовать отступ перед закрывающим идентификатором.  
Такой же отступ автоматически удаляется из каждой строки внутри heredoc.

Пример:
```php
<?php
echo <<<END
    а
    б
    в
    END;
```
Результат:
```
а
б
в
```

При этом количество пробелов или табуляций в каждой строке должно быть одинаковым.  
Если отступы отличаются или смешаны табы и пробелы — возникает ошибка `ParseError`.

## Правила интерполяции и экранирования

Heredoc ведет себя как строки в **двойных кавычках**:
- переменные подставляются в текст,
- управляющие последовательности (например, `\n`, `\t`, `\x41`, `\u{41}`) интерпретируются,
- не нужно экранировать кавычки (одинарные и двойные).

Пример:
```php
<?php
$name = "Расмус";
echo <<<EOT
Меня зовут "$name".
EOT;
```
Результат:
```
Меня зовут "Расмус".
```

Можно использовать heredoc внутри выражений, присваиваний, массивов, аргументов функций и даже при инициализации свойств и констант.

---

## Использование в аргументах функции

```php
<?php
var_dump(array(<<<EOD
foobar!
EOD
));
```
Результат:
```
array(1) {
  [0]=>
  string(7) "foobar!"
}
```

---

## Использование в константах и свойствах класса

```php
<?php
class Foo {
    const BAR = <<<TXT
Это пример константы.
TXT;

    public $baz = <<<TXT
Это пример свойства класса.
TXT;
}
```

---

## Heredoc с кавычками в идентификаторе

Идентификатор можно обрамить кавычками, чтобы избежать конфликтов с зарезервированными словами:

```php
<?php
echo <<<"FOOBAR"
Привет, мир!
FOOBAR;
```

Такой синтаксис полностью идентичен обычному heredoc.

---

## Пример многострочного текста с переменными

```php
<?php
$name = "Джон";
$time = "вечер";

echo <<<GREETING
Привет, $name!
Хорошего тебе $time!
GREETING;
```
Результат:
```
Привет, Джон!
Хорошего тебе вечер!
```

---

## Ошибки синтаксиса

1. Если после `<<<` стоит пробел перед идентификатором, возникнет `ParseError`.
2. После идентификатора обязательно должен быть перевод строки.
3. Закрывающий идентификатор должен стоять строго в начале строки (или с тем же отступом, что и открытие в PHP 7.3+).
4. Если внутри текста встретится строка, совпадающая с идентификатором, она будет воспринята как конец блока.

## Отличие от Nowdoc

- **Heredoc** работает как строки с двойными кавычками: интерполяция переменных и управляющие символы разрешены.
- **Nowdoc** (оператор `<<<'ID'`) работает как строки в одинарных кавычках: переменные не подставляются, управляющие последовательности не обрабатываются.

Пример сравнения:

```php
<?php
$name = "PHP";

// Heredoc
echo <<<HEREDOC
Язык $name — динамический.
HEREDOC;

// Nowdoc
echo <<<'NOWDOC'
Язык $name — динамический.
NOWDOC;
```
Результат:
```
Язык PHP — динамический.
Язык $name — динамический.
```

## Пример использования Heredoc для SQL-запросов

```php
<?php
$query = <<<SQL
SELECT id, name, email
FROM users
WHERE status = 'active'
ORDER BY name ASC;
SQL;

print_r($query);
```
Это особенно удобно при работе с большими фрагментами текста, шаблонами или SQL-запросами.

---

## Заключение

Heredoc — мощный инструмент для создания многострочных строк в PHP.  
Он сочетает гибкость двойных кавычек и удобство записи текста без необходимости экранирования символов.  
Современные версии PHP (7.3+) сделали синтаксис heredoc ещё удобнее благодаря поддержке отступов.
