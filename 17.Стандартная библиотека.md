## Стандартная библиотека PHP

PHP поставляется с набором встроенных функций, составляющих **стандартную библиотеку**.  
В неё входят **тысячи функций**, охватывающих работу со строками, числами, массивами, файлами, сетевыми протоколами и другими аспектами.

Запомнить все функции невозможно — да это и не требуется.  
Главное — понимать, где искать нужную информацию и как пользоваться документацией.

Любой программист должен знать:
- где искать официальную документацию;
- как определить нужный раздел по типу данных или задаче;
- как читать сигнатуру функции и понимать её поведение.

Программирование без интернета невозможно — доступ к документации является частью работы разработчика.

## Полезные рекомендации

1. **Следи за типами данных.**  
   Функции сгруппированы по категориям.  
   Например, функции для строк находятся в разделе *строковые функции*, для чисел — в *математических*.

2. **Периодически изучай стандартные функции.**  
   Заглядывай в раздел документации, связанный с текущей темой обучения.  
   Ознакомься с сигнатурами и примерами использования.

3. **Читай чужой код.**  
   Особенно полезно изучать исходники библиотек и фреймворков на GitHub.  
   Так можно увидеть реальные примеры применения встроенных функций.

4. **Помни о доступности стандартных функций.**  
   Функции стандартной библиотеки **глобальны** — их можно вызывать из любого места программы.  
   Это не относится к функциям, написанным вручную.

5. **Функции сгруппированы по назначению.**  
   Например:
   - функции для работы со строками (`strrev`, `strlen`, `strpos`);
   - функции для работы с массивами (`array_sum`, `array_merge`, `count`);
   - функции для чисел (`abs`, `round`, `pow`);
   - функции для файлов, дат, сетевых запросов и др.

Изучение стандартной библиотеки — это постоянный процесс, который идёт вместе с практикой программирования.
