## Создаем переменную

Допустим, нужно напечатать слово «Father!» два раза:

```php
<?php

print_r('Father!');
print_r('Father!');
```

Так можно сделать, но если слово будет использоваться часто, придётся повторять код.  
Чтобы избежать этого, создают **переменную**:

```php
<?php

// greeting — переводится как приветствие
$greeting = 'Father!';
print_r($greeting);
print_r("\n");
print_r($greeting);
// => Father!
// => Father!
```

Переменные в PHP начинаются со знака `$`.  
Выражение `$greeting = 'Father!'` означает, что значение `'Father!'` присваивается переменной `$greeting`.

## Использование переменной

Переменная подставляется в код вместо значения.  
Интерпретатор подставляет содержимое переменной и выполняет выражение.

Для имени переменной можно использовать:
- буквы латинского алфавита,
- цифры,
- символ `_` (нижнее подчеркивание).

Имя **не может начинаться с цифры**.  
Переменные чувствительны к регистру: `$hello` и `$heLLo` — разные переменные.

Количество переменных не ограничено.  
Их рекомендуется объявлять ближе к месту использования.

## Изменение переменной

Переменные могут менять своё значение:

```php
<?php

$greeting = 'Father!';
print_r($greeting); // => Father!

$greeting = 'Mother!';
print_r($greeting); // => Mother!
```

Имя переменной остаётся тем же, но значение другое.  
Переменные не требуют предварительного объявления — они создаются при первом использовании.

Разработчики анализируют значения переменных при **отладке**, чтобы понять, почему программа работает не так, как ожидалось.

## Ошибки при работе с переменными

Если обратиться к переменной до её объявления, программа выдаст ошибку:

```php
<?php

print_r($greeting);
$greeting = 'Father!';
// PHP Notice:  Undefined variable: greeting
```

Ошибка говорит о том, что переменная `$greeting` не определена.  
Также ошибка может возникнуть из-за опечаток в имени переменной.

Современные редакторы подсвечивают такие случаи и помогают избежать подобных ошибок.

## Константы

**Константы** — это значения, которые не меняются.  
Например, число π всегда равно 3.14.

```php
<?php

const PI = 3.14;
print_r(PI); // => 3.14
```

Создание константы начинается с ключевого слова `const`.  
Перед именем не ставится `$`.  
Константы принято записывать **в верхнем регистре** с `_` в качестве разделителя.

Пример встроенных констант PHP:
- `PHP_VERSION` — текущая версия PHP;
- `PHP_MAXPATHLEN` — максимальная длина имени файла;
- `PHP_INT_MAX` — максимальное значение целых чисел.

### Магические константы

Магические константы начинаются и заканчиваются двумя символами подчеркивания `__`.  
Их нельзя определять самостоятельно, но можно использовать.

Примеры:
- `__LINE__` — номер текущей строки;
- `__FILE__` — путь до текущего файла;
- `__DIR__` — путь до директории, в которой находится файл.

Эти константы могут иметь разные значения в разных частях программы,  
но изменения предсказуемы и безопасны.

## Heredoc

Строки можно определять с помощью **heredoc-синтаксиса**.  
После оператора `<<<` указывается идентификатор, затем сам текст,  
а потом идентификатор повторяется для закрытия блока.

```php
<?php

$str = <<<EOT
Пример строки,
охватывающей несколько строк,
с использованием heredoc-синтаксиса.
Здесь не нужно экранировать ни одинарные ', ни двойные " кавычки.
EOT;

print_r($str);
```

Результат:

```
Пример строки,
охватывающей несколько строк,
с использованием heredoc-синтаксиса.
Здесь не нужно экранировать ни одинарные ', ни двойные " кавычки.
```

Перед закрывающим идентификатором не должно быть отступа,  
иначе PHP сообщит об ошибке синтаксиса.
