В предыдущих уроках функции завершали работу тем, что **печатают** данные на экран.  
Однако в реальных программах важно не просто что-то вывести, а **использовать результат** работы функции в дальнейшем.

---

## Зачем нужен возврат значений

Пример функции, которая только печатает текст:

```php
<?php

function greeting()
{
    print_r('Hello, Hexlet!');
}
```

Такая функция выводит сообщение, но не возвращает никакого значения.  
Если попытаться сохранить результат в переменную:

```php
$message = greeting();
var_dump($message); // => NULL
```

PHP выведет `NULL`, потому что функция ничего не возвращает.

Чтобы результат можно было использовать в программе, нужно **возвращать значение**.  
Для этого применяется ключевое слово `return`.

---

## Пример обработки email

Допустим, пользователь вводит email с ошибками: пробелами и разным регистром.  
Перед сохранением его нужно «очистить»: убрать пробелы и привести к нижнему регистру.

```php
<?php

function saveEmail()
{
    $email = "  SuppORT@hexlet.IO";
    // Убираем пробелы по краям
    $trimmedEmail = trim($email);
    // Приводим к нижнему регистру
    $preparedEmail = strtolower($trimmedEmail);
    print_r($preparedEmail);
    // Здесь могла бы быть запись в базу данных
}
```

Функции `trim()` и `strtolower()` **не печатают** результат — они его **возвращают**.  
Именно поэтому можно записать их результат в переменные.

## Как работает return

`return` — это инструкция, которая берёт выражение справа и **передаёт результат наружу**.  
После `return` выполнение функции **останавливается**.

```php
<?php

function greeting()
{
    return 'Hello, Hexlet!';
}

// Теперь можно использовать результат
$message = greeting();
print_r($message); // => 'Hello, Hexlet!'
print_r(strtoupper($message)); // => 'HELLO, HEXLET!'
```

Код, который стоит после `return`, **никогда не выполняется**:

```php
<?php

function greeting()
{
    return 'Hello, Hexlet!';
    print_r('Я никогда не выполнюсь');
}
```

## Возврат и печать

Функция может одновременно **печать** и **возвращать** значение:

```php
<?php

function greeting()
{
    print_r('Я появлюсь в консоли');
    return 'Hello, Hexlet!';
}

$message = greeting();
```

В этом случае на экран выведется строка `'Я появлюсь в консоли'`,  
а в переменную `$message` запишется `'Hello, Hexlet!'`.

---

## Возврат выражений

`return` может возвращать **любое выражение** — не только конкретное значение.

```php
<?php

function greeting()
{
    $message = 'Hello, Hexlet!';
    return $message; // возвращает значение переменной
}
```

или:

```php
<?php

function doubleFive()
{
    $result = 5 + 5;
    return $result;
}
```

Можно даже короче:
```php
return 5 + 5;
```
