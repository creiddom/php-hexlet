## Изоляция функций

Рассмотрим следующий пример кода и подумаем, какое значение окажется в переменной `$result`:

```php
<?php

$age = 5;

function generate()
{
    return $age + 3;
}

$result = generate();
```

📘 **Ответ:** код завершится ошибкой.

Почему? Потому что внутри функции нет переменной с именем `$age`,  
а функция пытается к ней обратиться.  

Функция **изолирована от внешних переменных**.  
Переменные, объявленные снаружи, не видны внутри функции.  
То, что определено в теле функции, существует только во время её выполнения.  
Такое поведение называется **областью видимости** (scope).

---

## Пример с переменными

```php
<?php

$age = 5;

function changeAge()
{
    $age = 8;
}

changeAge();

print_r($age); // => 5
```

Здесь функция `changeAge()` создаёт **локальную переменную `$age`**,  
которая никак не связана с внешней `$age`.  

После вызова функции значение внешней переменной **не изменилось**,  
потому что изменение внутри функции не влияет на данные снаружи.

🔹 Таким образом, каждая функция работает в **своём окружении**.  
Это помогает избегать конфликтов имён и ошибок, связанных с изменением внешних данных.

## Константы и область видимости

В отличие от переменных, **константы** ведут себя иначе.  
Они доступны везде — и вне функции, и внутри.

```php
<?php

const AGE = 5;

function generate()
{
    return AGE + 3;
}

$result = generate();

print_r($result); // => 8
```

✅ В этом случае программа отработает без ошибок.  
Константа `AGE` доступна внутри функции, так как область видимости констант — **глобальная**.  

Это значит, что константы можно использовать в любой части программы,  
в отличие от переменных, которые живут только в рамках своего окружения.

---

## Выводы

- Каждая функция имеет **своё локальное окружение**.  
- Переменные, объявленные снаружи, **не видны внутри функций**.  
- Локальные переменные, созданные в функции, **не влияют на внешние**.  
- Константы доступны везде — и внутри функций, и снаружи.  
- Изоляция функций делает код надёжнее и предотвращает случайное изменение данных.
