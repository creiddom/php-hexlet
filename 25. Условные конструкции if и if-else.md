## if

Задача предиката — получить ответ на вопрос, но часто требуется выполнить действие в зависимости от ответа.  
Рассмотрим пример функции, определяющей тип предложения — обычное или вопросительное:

```php
<?php

function getTypeOfSentence($sentence)
{
    // Простой способ извлечь последний символ
    $lastChar = $sentence[-1];
    if ($lastChar === '?') {
        return 'question';
    }

    return 'normal';
}

getTypeOfSentence('Hodor');  // normal
getTypeOfSentence('Hodor?'); // question
```

Инструкция `if` принимает **выражение-предикат** в скобках и выполняет код внутри фигурных скобок, если предикат истинный (`true`).  
Если предикат ложный (`false`), блок кода пропускается и выполнение продолжается дальше.

## else

Добавим в функцию `else`, чтобы вернуть не просто тип, а полноценное предложение:

```php
<?php

function getTypeOfSentence($sentence)
{
    $lastChar = $sentence[-1];

    if ($lastChar === '?') {
        $sentenceType = 'question';
    } else {
        $sentenceType = 'normal';
    }

    return "Sentence is {$sentenceType}";
}

getTypeOfSentence('Hodor');  // Sentence is normal
getTypeOfSentence('Hodor?'); // Sentence is question
```

Блок `else` выполняется **только если условие в `if` не выполнено**.  

Также возможна инверсия проверки — через отрицание (`!==`), но чаще выбирают **вариант без отрицаний**, потому что он читается проще:

```php
<?php

function getTypeOfSentence($sentence)
{
    $lastChar = $sentence[-1];

    if ($lastChar !== '?') {
        $sentenceType = 'normal';
    } else {
        $sentenceType = 'question';
    }

    return "Sentence is {$sentenceType}";
}
```

## elseif

Функция `getTypeOfSentence()` различает только два типа предложений.  
Добавим поддержку восклицательных знаков:

```php
<?php

function getTypeOfSentence($sentence)
{
    $lastChar = $sentence[-1];

    if ($lastChar === '!') {
        $sentenceType = 'exclamation';
    } else {
        $sentenceType = 'normal';
    }

    if ($lastChar === '?') {
        $sentenceType = 'question';
    }

    return "Sentence is {$sentenceType}";
}

getTypeOfSentence('Who?'); // 'Sentence is question'
getTypeOfSentence('No');   // 'Sentence is normal'
getTypeOfSentence('No!');  // 'Sentence is exclamation'
```

Технически функция работает, но логика не идеальна:
- Проверка `?` выполняется всегда, даже если `!` уже найден.
- Ветка `else` относится только к первому `if`.

Правильнее объединить условия в одну конструкцию с `elseif`:

```php
<?php

function getTypeOfSentence($sentence)
{
    $lastChar = $sentence[-1];

    if ($lastChar === '?') {
        $sentenceType = 'question';
    } elseif ($lastChar === '!') {
        $sentenceType = 'exclamation';
    } else {
        $sentenceType = 'normal';
    }

    return "Sentence is {$sentenceType}";
}
```

Теперь выполняется **только одно** из трёх действий — первое, условие которого оказалось истинным.

## Выводы

- `if` выполняет блок кода, если условие истинно.  
- `else` выполняет альтернативный блок, если условие ложно.  
- `elseif` позволяет добавить дополнительные проверки.  
- Выполняется только один из блоков в цепочке `if` / `elseif` / `else`.  
- Лучше избегать отрицаний в условиях, если это не нужно — так код читается проще.
