## Особенность выражений

В программировании выражение — это нечто, что **возвращает результат**, который можно использовать.  

Математические и строковые операции — это примеры выражений:

```php
<?php

1 + 5 * 3;
'He' . 'Let';

// Переменные тоже могут быть частью выражения
$rate * 5;
```

Главная особенность выражений в том, что они **возвращают значение**, которое можно присвоить переменной или вывести на экран.

```php
<?php

// Здесь выражение — это 1 + 5
$sum = 1 + 5;
print_r(1 + 5);
```

Выражения можно комбинировать, создавая более сложное поведение.  
Понимание выражений помогает лучше видеть, как отдельные части кода соединяются в единое целое.

---

## Является ли функция выражением

Функции **возвращают результат**, а значит, они тоже являются выражениями.  
Это позволяет использовать вызовы функций **внутри других выражений**, например в математических операциях.

Пример — получение индекса последнего символа в слове:

```php
<?php

$name = 'php';
// Индексы начинаются с нуля
// Вызов функции и вычитание вместе!
$lastIndex = strlen($name) - 1;
print_r($lastIndex); // 2
```

Здесь нет нового синтаксиса — просто объединены известные конструкции.

Можно записать короче:

```php
<?php

$name = 'php';
print_r(strlen($name) - 1); // => 2
```

Такой подход работает с любыми функциями.  
Например, со строковыми и интерполяцией:

```php
<?php

$name = 'Toto';
// Интерполяция переменной внутри строки
print_r("Имя пользователя: {$name}");
// => Имя пользователя: Toto
```

---

## Выводы

- **Выражение** — это часть кода, которая возвращает значение.  
- **Функция** — тоже выражение, потому что возвращает результат.  
- Вызовы функций можно использовать внутри других выражений.  
- Комбинирование выражений позволяет создавать более гибкий и выразительный код.
