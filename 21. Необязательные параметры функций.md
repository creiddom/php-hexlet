## Что такое необязательные параметры

Во многих функциях и методах встречаются параметры, значения которых редко меняются.  
В таких случаях им задают **значения по умолчанию** — это позволяет вызывать функцию без лишнего дублирования аргументов.

---

## Значения по умолчанию

Чтобы параметр стал необязательным, ему присваивают значение по умолчанию прямо в определении функции.

```php
<?php

// Функция возведения в степень
// Второй параметр имеет значение по умолчанию 2
function myPow($x, $base = 2)
{
    return $x ** $base;
}

// Три во второй степени (второй аргумент не передан, берётся 2)
myPow(3); // => 9

// Три в третьей степени (значение по умолчанию переопределено)
myPow(3, 3); // => 27
```

Значение по умолчанию работает **только если аргумент не передан**.  
Если значение передано явно — оно переопределяет стандартное.

---

## Примеры использования

Необязательный параметр может быть даже один:

```php
<?php

function myPrint($text = 'nothing')
{
    print_r($text);
}

myPrint();        // => "nothing"
myPrint("Hexlet"); // => "Hexlet"
```

Можно задать сколько угодно параметров со значениями по умолчанию:

```php
<?php

function f($a = 5, $b = 10, $c = 100)
{
    // ...
}
```

---

## Ограничения

Все параметры со значениями по умолчанию **должны находиться в конце списка параметров**.  
PHP не позволяет располагать обязательные параметры **после** необязательных.

```php
<?php

// ❌ Ошибка: обязательный параметр $x стоит после необязательных
function f($a = 5, $b = 10, $c = 100, $x)
{
    // ...
}

// ❌ Ошибка: обязательный параметр в середине списка
function f($a = 5, $b = 10, $x, $c = 100)
{
    // ...
}

// ✅ Корректные варианты
function f($x, $a = 5, $b = 10, $c = 100)
{
    // ...
}

function f($x, $y, $a = 5, $b = 10, $c = 100)
{
    // ...
}
```

Причина проста: при вызове функции PHP должен понимать, какие параметры были пропущены,  
а если обязательные идут после необязательных, порядок становится неоднозначным.

---

## Выводы

- Параметры с **значением по умолчанию** становятся **необязательными**.  
- При вызове функции без аргумента используется значение по умолчанию.  
- Если аргумент передан, он **заменяет стандартное значение**.  
- Все необязательные параметры должны располагаться **в конце списка**.  
- Это помогает сделать функции гибкими и уменьшить количество одинакового кода.
