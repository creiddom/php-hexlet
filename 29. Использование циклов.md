# Использование циклов
**Основы PHP**

## Агрегация данных (числа) и зачем нужны циклы

Есть отдельный класс задач, который не может обойтись без циклов — **агрегация данных**: поиск суммы, минимума/максимума, среднего и т. п. Общая особенность — результат зависит от **всего набора значений**.

Разберём сумму чисел в диапазоне `[start, finish]` (границы включительно).

```php
<?php

sumNumbersFromRange(5, 7); // 5 + 6 + 7 = 18
sumNumbersFromRange(1, 2); // 1 + 2 = 3
sumNumbersFromRange(1, 1); // 1
sumNumbersFromRange(100, 100); // 100

function sumNumbersFromRange($start, $finish)
{
    // Счётчик начинаем с левой границы
    $i = $start;
    // Нейтральный элемент для сложения — 0
    $sum = 0;

    // Идём до правой границы включительно
    while ($i <= $finish) {
        $sum = $sum + $i; // накапливаем
        $i = $i + 1;      // следующий элемент
    }

    return $sum;
}
```
**Структура цикла** здесь типовая:
- инициализация счётчика;
- предикат останова;
- изменение счётчика.

Число итераций: `finish - start + 1`.

Если не задать начальное значение аккумулятора, возникнет `Undefined variable` (и логические ошибки). Нейтральные элементы:
- для сложения — `0`;
- для вычитания — `0`;
- для конкатенации строк — `''` (пустая строка).

## Агрегация данных (строки)

Иногда нужно *динамически формировать строку* — заранее неизвестно её содержимое и длина. Пример: «умножить» строку — повторить её `N` раз.

```php
<?php

repeat('hexlet', 3); // 'hexlethexlethexlet'

function repeat($text, $times)
{
    // Нейтральный элемент для строк — пустая строка
    $result = '';
    $i = 1;

    while ($i <= $times) {
        $result = "{$result}{$text}";
        $i = $i + 1;
    }

    return $result;
}
```

Пошагово для `repeat('hexlet', 3)`:
```php
$result = '';
$result = "{$result}hexlet"; // hexlet
$result = "{$result}hexlet"; // hexlethexlet
$result = "{$result}hexlet"; // hexlethexlethexlet
```

## Обход строк посимвольно

Благодаря индексации можно обойти строку по символам.

```php
<?php

function printNameBySymbol($name)
{
    $i = 0;
    // Идём до конца строки: последний допустимый индекс — strlen($name) - 1
    while ($i < strlen($name)) {
        print_r("{$name[$i]}\n");
        $i = $i + 1;
    }
}

$name = 'Arya';
printNameBySymbol($name);
// => A
// => r
// => y
// => a
```

Эквивалентные условия цикла:
- `$i < strlen($name)`
- `$i <= strlen($name) - 1`

## Формирование строк в циклах: переворот строки

Классическая задача: развернуть строку. Базовый способ — наращивать результат слева текущим символом.

```php
<?php

function reverse($str)
{
    $i = 0;
    $result = ''; // нейтральный элемент

    while ($i < strlen($str)) {
        $currentChar = $str[$i];
        $result = "{$currentChar}{$result}";
        // то же через конкатенацию:
        // $result = $currentChar . $result;
        $i = $i + 1;
    }

    return $result;
}

reverse('Hexlet'); // 'telxeH'
reverse('Bran');   // 'narB'
reverse('');       // ''
```

Механика: каждый следующий символ приклеивается **слева**, поэтому итог — перевёрнутая строка.

## Итерации цикла: три столпа

1) **Инициализация** счётчика/аккумулятора.  
2) **Условие продолжения** (предикат).  
3) **Изменение** счётчика/аккумулятора на каждой итерации.

Нарушение любого пункта приводит к ошибкам — вплоть до **зацикливания** (бесконечного цикла).

Пример зацикливания (нет изменения счётчика):
```php
<?php

function printNumbers($lastNumber)
{
    $i = 1;
    while ($i <= $lastNumber) {
        print_r($i); // $i не меняется!
    }
    print_r('finished!');
}
```

Иногда бесконечные циклы нужны осознанно:
```php
while (true) {
    // что-то делаем
}
```
